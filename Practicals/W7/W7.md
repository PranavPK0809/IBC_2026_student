### 1. Extract US ZIP Codes

I imported the `re` module so that I could use regular expressions. Used `re.findall()` to find five-digit numbers. The code`\b\d{5}\b` looks for exactly five number sequence. Each ZIP code found was added to the `zip_codes` list.

```python
import re

with open("pubmed_results.txt", "r") as f:
    for line in f:
        line = line.rstrip()

zip_codes = []

with open("pubmed_results.txt", "r") as f:
    for line in f:
        line = line.rstrip()
        
        zips = re.findall(r"\b\d{5}\b", line)
        
        for zipcode in zips:
            zip_codes.append(zipcode)

print(zip_codes)
```

### 2. Create ZIP Code, Longitude, Latitude, and Count Lists

I imported the `csv` module and created four empty lists called `zip_code`, `zip_long`, `zip_lat`, and `zip_count`. 
I used `csv.DictReader()` to read the ZIP code coordinate file. I checked whether the ZIP codes in the coordinate file was present in the ZIP codes extracted from the PubMed results. When it is present, I then add its ZIP code, latitude, longitude, and number of occurrences to the lists.

```python
import csv

zip_code = []
zip_long = []
zip_lat = []
zip_count = []

with open("zipcodes_coordinates.txt", "r") as f:
    reader = csv.DictReader(f)

    for row in reader:
        if row["ZIP"] in zip_codes:
            zip_code.append(row["ZIP"])
            zip_lat.append(float(row["LAT"]))
            zip_long.append(float(row["LNG"]))
            zip_count.append(zip_codes.count(row["ZIP"]))
```

The four lists contain the ZIP codes found in both files, their longitude and latitude coordinates, and the number of times each ZIP code occurred.

### 3. Plot the Results

I used the provided plotting code from GitHub to plot the ZIP code data. 
The longitude and latitude are used to determine the location of each point
`zip_count` is used for the size and color of the points.

