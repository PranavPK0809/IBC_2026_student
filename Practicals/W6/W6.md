### Question 2

For this, I used pdb to find the bug in the code. The original function gave me:

```text
'MNLLEV'
```

The desired amino acid serquence is  `MEFSL`, so I used pdb

```python
import pdb

def get_amino_acids(mRNA):
    i = 0
    aa_sequence = []
    while (i + 3) < len(mRNA):
        codon = mRNA[i:(i + 3)]
        aa = genetic_code[codon]
        pdb.set_trace()
        if aa == "Stop":
            break
        else:
            aa_sequence.append(aa)
        i = i + 4
    return "".join(aa_sequence)
```
When the debugger first stopped, I checked `i`, `codon`, and `aa` and got:

```text
i = 0
codon = 'AUG'
aa = 'M'
```
Used `c` to continue to the next breakpoint. This time I got:

```text

codon = 'AAU'
```
This showed me that `i` was going from 0 to 4. I found that the problem was:

```python

```
and changed it to

```python

```

After the fix, I ran the function again and got:

```text
'MEFSL'
```
This result matched the expected result.


## Gobbler Proteins
For this final problem, I used the `get_amino_acids()` to translate the turkey sequences. 15 DNA sequences needed to be changed into amino acid sequences.

```python
with open("Turkey_transcripts_15_coding.fasta", "r") as infile, open("Turkey_proteins_15.fasta", "w") as outfile:

    for line in infile:
        line = line.rstrip()

        if line[0] == ">":
            parts = line.split("gbkey=CDS")
            new_header = parts[0] + "gbkey=AA"
            outfile.write(new_header + "\n")

        else:
            mrna = ""

            for base in line:
                if base == "T":
                    mrna = mrna + "U"
                else:
                    mrna = mrna + base

            protein = get_amino_acids(mrna)
            outfile.write(protein + "\n")
```

The new translated sequences are in a new file called `Turkey_proteins_15.fasta`. I also checked to make sure all the 15 sequences were in the file.

