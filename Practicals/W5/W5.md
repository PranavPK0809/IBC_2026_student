## Baking a Cake

The purpose of this problem was to write a detailed script in pseudocode for baking a cake.

```text
mix flour, eggs, milk, butter, and sugar into a batter
put batter into an oven pan
set oven to 400 degrees F
bake cake for 20 minutes
check cake with a knife

while the knife does not come out clean
    bake cake for more time
    check cake with knife again

remove cake from oven
```

This pseudocode starts by mixing the ingredients and placing the batter into a pan. The cake is baked at 400 degrees Fahrenheit for 20minutes initially and checked with a knife. A while condition is used so that the cake continues baking until the knife comes out clean. If it does not, the cake is baked further. 




## Fizz Buzz

The purpose of the problem was to write pseudocode and a Python program for the Fizz Buzz game from 1 to 100. The pseudocode

```text
for each number from 1 to 100
    if number is divisible by both 3 and 5
        print "fizzbuzz"
    else if number is divisible by 3
        print "fizz"
    else if number is divisible by 5
        print "buzz"
    else
        print number
```

For this problem, I used a loop to go through numbers from 1 to 100. Each number was checked to see whether it was divisible by both 3 and 5, and I checked which ones were divisible by 3 and then 5. Both conditions and their individual conditions were checked. 


### Python Script

The Python program for this problem is included in `fizz_buzz.py`.

```python
# Loop through numbers 1 to 100
for i in range(1, 101):
# Checking if the numbers are divisible by both 3 and 5

    if i % 3 == 0 and i % 5 == 0:
        print("fizzbuzz")
        
#Checking if the numbers are divisible by 3
    elif i % 3 == 0:
        print("fizz")

#Checking if the numbers are divisible by 5    
    elif i % 5 == 0:
        print("buzz")

# If neither of the conditions are met, then just print the number
    else:
        print(i)
```


## GC Content from FASTA
The purpose of this problem was to calculate the GC content of the 15 coding sequences in `Turkey_transcripts_15.fasta` and write the sequence names and GC contents to a new file named gc_content.txt

### Python Script

The Python program for this problem is included in `gc_content.py`.

```python
# Open the fasta file and get contents from the Turkey file and create the results file
with open("Turkey_transcripts_15.fasta", "r") as infile, open("gc_content.txt", "w") as outfile:

#Go through the file two lines at a time
    for i, line in enumerate(infile):
        line = line.rstrip()

#Save the sequence name
        if i % 2 == 0:
            gene_id = line.split()[0]

#Calculate GC content for the sequence
        else:
            seq = line
            gc = (seq.count("G") + seq.count("C")) / len(seq)
            outfile.write(gene_id + "\t" + str(gc) + "\n")
```

This program opens the FASTA file and goes through each line. The sequence name is saved from the header line, and the DNA sequence is used to calculate GC content. 
GC content is calculated by adding the number of G and C bases and dividing by the total sequence length. 
The results are saved in the`gc_content.txt`
